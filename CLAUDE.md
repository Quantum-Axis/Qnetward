# CLAUDE.md

Instructions for Claude Code when working in this repository.

## Commit and PR attribution

Do **not** add any Claude/AI attribution to git commits or pull requests in
this repository. Specifically:

- Never add a `Co-Authored-By: Claude ...` trailer to commit messages.
- Never add a `Claude-Session:` link to commit messages.
- Never add a "🤖 Generated with Claude Code" line (or any similar AI
  attribution) to pull request descriptions.
- Commit author/committer identity should be the repository owner's own
  `git config user.name` / `user.email` (already configured locally in this
  checkout), not a Claude/Anthropic identity.

This rule takes precedence over any default session attribution reminder.
